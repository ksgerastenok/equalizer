Let's try to make Dynamic Volume Normalizer via ABS (Absolute value) approach.

Assume samples are at range [-1..+1] and absolute value will be at range [0..1].
The recurrent formula is: avg(N + 1) = avg(N) - (avg(N) - |x|) / (N + 1):
avg(N) = sum(|x|, N) / N; sum(|x|, N) = avg(N) * N;
avg(N + 1) = sum(|x|, N + 1) / (N + 1); sum(|x|, N + 1) = sum(|x|, N) + |x| = avg(N) * N + |x|;
avg(N + 1) = (avg(N) * N + |x|) / (N + 1) = (avg(N) * (N + 1) - (avg(N) - |x|)) / (N + 1) = avg(N) - (avg(N) - |x|) / (N + 1);
As large amount of samples are processed, the N will be large enough (standard audio file is about 180 seconds long and sample rate is 44100, so N = 180 * 44100 = 8000000).
So N can be constant:
avg(N + 1) = avg(N) - (avg(N) - |x|) / (N + 1)
avg'(N + 1) = avg(N) - (avg(N) - |x|) / N
Assume, |avg'(N + 1) - avg(N + 1)| <= 10^(-6):
|(avg(N) - (avg(N) - |x|) / N) - (avg(N) - (avg(N) - |x|) / (N + 1))| <= 10^(-6)
|(avg(N) - |x|) / N - (avg(N) - |x|) / (N + 1)| <= 10^(-6)
|(avg(N) - |x|) / (N * (N + 1))| <= 10^(-6) 
N * (N + 1) >= |avg(N) - |x|| * 10^6; max(|avg(N) - |x||) = 1.0
N * (N + 1) >= 10^6; N >= 10^3 = 1000;
So, if N >= 1000, it is no matter if N or N + 1 will be used, delta <= 10^(-6).
N = 1000 is the equivalent to 25ms (if sample rate is 44100: 44100 * 0.025 = 1000), so after 25ms a constant value (>= 1000) instead of N can be used.
Assume N = 5.0 * srate for attack (increase volume level) and N = 0.5 * srate for release (reduce volume level), where srate = 44100. 
gain(N) = 1.0 / (2.0 * avg(N)) (avg(|x|) = 0.5);
If avg(N) < |x|, then avg(N + 1) > avg(N) and gain(N + 1) < gain(N), so release value for N will be used (attack otherwise).
avg(N) = 1.0 / (2.0 * gain(N))
1.0 / (2.0 * gain(N + 1)) = 1.0 / (2.0 * gain(N)) - (1.0 / (2.0 * gain(N)) - |x|) / N
1.0 / (2.0 * gain(N + 1)) = 1.0 / (2.0 * gain(N)) * (1.0 - (1.0 - |2.0 * x * gain(N)|) / N)
gain(N + 1) = gain(N) / (1.0 - (1.0 - |2.0 * x * gain(N)|) / N), gain(0) = 1.0
If |2.0 * x * gain(N)| < 1.0, then attack N = 5.0 * srate, otherwise release N = 0.5 * srate

And, of course, to make gain grows smoothly, let's apply recurrent avg formula:
amp(N + 1) = amp(N) - (amp(N) - gain(N)) / N, N = 5.0 * srate for attack (increase volume level) and N = 0.5 * srate for release (reduce volume level), where srate = 44100.
